# Help, onboarding and product copy handoff

Status: implementation-ready copy system  
Prepared: 7 October 2026  
Baseline: [German Master 2.0 blueprint](blueprint.md)  
Related: [learner screens UX](learner-screens-ux.md), [account/auth UX](account-auth-ux.md)

This document completes the remaining ChatGPT product-completion copy work from
[plan-of-work.md](plan-of-work.md). It provides concise onboarding guidance,
help text, terminology and system-status language for web and Android.

It intentionally does not add new product features.

## 1. Voice

German Master should sound:
- calm,
- precise,
- supportive,
- adult,
- concise.

Do not use:
- childish praise,
- shame,
- streak pressure,
- exaggerated claims,
- certified-level language,
- AI-assistant language in the core learner journey.

Preferred:
- “Needs practice”
- “Let’s try this again later”
- “Saved on this device”
- “Progress updated”

Avoid:
- “Weak”
- “Failed”
- “Level up!”
- “Perfect streak”
- “AI says…”

German uses **du** consistently.

## 4. “How German Master works”

Use as a compact Help section.

### EN

**1. Practise**  
German Master mixes topics that need attention with useful review.

**2. Understand**  
After each answer, you see the accepted form and a short explanation.

**3. Revisit**  
A correct answer helps, but one answer is not enough to prove mastery. German Master schedules later unassisted checks.

**4. Retain**  
A target becomes reliable only after enough evidence across time. Later retention checks make sure it still holds.

### DE

**1. Üben**  
German Master mischt Themen, die Aufmerksamkeit brauchen, mit sinnvoller Wiederholung.

**2. Verstehen**  
Nach jeder Antwort siehst du die richtige Form und eine kurze Erklärung.

**3. Wiederholen**  
Eine richtige Antwort hilft, reicht aber nicht für einen sicheren Lernstand. German Master plant spätere selbstständige Überprüfungen.

**4. Behalten**  
Ein Thema gilt erst nach ausreichenden Ergebnissen über einen längeren Zeitraum als sicher. Spätere Wiederholungen prüfen, ob es weiterhin sitzt.

**Eine richtige Antwort ist ein wichtiger Hinweis, aber noch kein Beweis dafür, dass die Form später weiterhin sicher sitzt. Für einen sicheren Lernstand zählen wiederholte selbstständige Überprüfungen über einen längeren Zeitraum.**

## 16. System status glossary

Use these consistently.

| Meaning | English | German |
| --- | --- | --- |
| local durable save | Saved on this device | Auf diesem Gerät gespeichert |
| waiting upload | Waiting to sync | Wartet auf Synchronisierung |
| authoritative accepted state | Progress updated | Fortschritt aktualisiert |
| no network | Offline | Offline |
| stale server snapshot | Last confirmed progress | Zuletzt bestätigter Fortschritt |
| prepared local session | Available offline | Offline verfügbar |
| assisted attempt | Answered with help | Mit Hilfe beantwortet |
| content report sent | Sent for review | Zur Prüfung gesendet |

Avoid “cloud saved” because it does not distinguish accepted evidence from
uploaded-but-not-yet-reconciled work.

## 19. Accessibility and localization copy rules

- Avoid instructions based only on position such as “click the green button”.
- Button labels describe the action, not “OK” where a clearer verb exists.
- Do not put essential explanations only in placeholders.
- Keep important status text concise enough for live-region announcements.
- German strings may be longer; layouts must wrap rather than abbreviate meaning.
- Use sentence case.
- Use ellipsis only when an action opens a follow-up step, such as “Delete account…”.
- Use locale-aware dates instead of hard-coded English month names.

## 20. Remaining human-copy boundary

The English/German product copy in these handoff documents is implementation
copy, not independent editorial certification of exercise content.

Independent German review remains required for:
- exercise prompts,
- accepted answers,
- hints,
- explanations,
- grammatical naturalness,
- ambiguity and level suitability.

Product UI wording may be reviewed during design/accessibility acceptance, but
it does not block the separate exercise-content review record.
