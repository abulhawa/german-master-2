# Shared learner terminology

Applies to renovated web and native Android; internal API enum names are unchanged.

| Meaning | English | German |
| --- | --- | --- |
| Progress heading | Your progress | Dein Lernstand |
| Target in navigation | Skill | Fähigkeit |
| Needs practice | Needs practice | Braucht Übung |
| Improving | Improving | Wird sicherer |
| Mastered under the existing retention policy | Mastered | Sicher |
| Qualifying evidence count | Review checks | Wiederholungsprüfungen |
| Pending local answer | Saved on this device; still waiting to sync | Auf diesem Gerät gespeichert; noch nicht synchronisiert |
| Provisional correct result | Looks correct — not synced yet | Sieht richtig aus — noch nicht synchronisiert |
| Changed result after sync | Updated result | Aktualisiertes Ergebnis |
| Reauthentication | Reconnect account | Konto erneut verbinden |
| Export | Download my learning data | Meine Lerndaten herunterladen |

Use informal du/dein in German interface instructions. Exercise dialogue may intentionally use Sie; do not rewrite exercise content as interface copy.

Keep local-only answers distinct from results saved to the account. Explain pending actions and data-loss consequences plainly. Avoid “server-confirmed,” “snapshot,” “fixture reset,” and internal event terminology in ordinary learner screens. Recovery copy must not imply that unsynced answers have already reached the account.

This is an implementation guide. Browser/device acceptance and the broader editorial pass remain deferred; owner-accepted TalkBack scope is unchanged.
