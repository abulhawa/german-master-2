# Study workspace redesign — 7 October 2026

The owner rejected the first sidebar implementation as still looking like a scaffold and explicitly asked to remove the many settings from the learning experience. This revision adopts a more distinctive study workspace while retaining the existing learning and account protocols.

- Guest entry has a wordmark, optional interface language, a large introduction and one practice action. Level and session-length forms no longer block the first question. Existing default preferences and the five-question starter remain; this is not a new content release or level test.
- Home has a blue session panel, clear primary action and optional topic exploration. Preferred/available counters, session details and technical synchronization controls are removed from Home. Topic counts are actual learning-target counts, not invented exercise availability. The letter-study artwork is decorative and hidden from assistive technology; it carries no learner scores or accepted answers.
- Account retains language, theme and a practice-preferences action. Offline operations and privacy/account operations are collapsed, accessible disclosures. Timezone/session length remain available in an additional-preferences disclosure to preserve conflict recovery and existing preference records. No account/export/deletion protection was removed.
- Login, guest entry and focused practice share the same typography, artwork and surfaces. Practice keeps its readable column, persisted drafts, explicit feedback/Continue and partial-session exit behavior.

The owner's simplified first-use instruction supersedes the earlier guest onboarding form specification. The blue panel and larger introductory typography deliberately evolve the restrained October 3 concept; blueprint behavior, semantic light/dark tokens, 48px controls, bilingual labels, keyboard focus, reduced motion and readable practice width remain the baseline. No legacy gamification, invented mastery or independent scheduling policy is introduced.
