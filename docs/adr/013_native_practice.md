# ADR 013: Durable debug native Practice

Accepted for the local fixture demonstration, 4 October 2026.

Extend the debug learner shell with mixed server-selected Practice. Save the stable session request and device ID before HTTP; request the saved profile question preference and explain shorter returned sessions. Preserve foundation previews, release navigation, application ID, signing and legacy storage.

Add nullable practice state to the existing version-one AtomicFile cache so prior profile/snapshot records remain readable. Save incomplete drafts, hint assistance, immutable pending attempts and skip events, server feedback, position and distinct graded/skipped/correct counters. A separate token-order draft permits a one-token selection that cannot yet satisfy the transport answer model. Validate completeness before freezing an attempt. Hint disclosure follows durable assistance storage. No client evaluates an answer or derives mastery.

Only accepted/duplicate acknowledgments linked to the frozen ID produce feedback or skip advancement. Persist acknowledgment and counters together; storage failure leaves the pending event available for identical replay. Pending answers exclude Skip; pending Skip excludes editing, hints and grading. Rejections retain saved work and block submissions. Explicit discard requires confirmation and removes only the local session, including pending work; it does not undo server evidence. Close retains practice. Existing sessions can resume while preferences await confirmation; pending preferences block new creation.

Completion refreshes the full confirmed target snapshot. Refresh failure preserves acknowledged summary counts and prior data, marks the snapshot stale and leaves Home refresh available. The repository mutex and UI busy lock serialize mutations within this activity. Small draft AtomicFile writes precede visible updates; this fixture design is not cross-process coordination or scalable production storage. Profile writes and snapshots remain independent from practice.

Focused practice hides Home/Progress/settings and uses bilingual copy, shared Material roles, heading/live-region semantics and 48dp actions. Device/TalkBack/font-scale/visual acceptance, production identity, downloaded offline grading and coordinated sync remain open. Native Topics/target focus is next. No production publication or release is authorized.
